# Flow Queue

Google Flow 的提示詞排隊工具（Chrome 擴充功能，Manifest V3）。

- **不需要登入**：沒有帳號、授權或付費機制。直接使用你目前 Chrome 設定檔裡已登入 Flow 的 Google 帳號。
- **不呼叫私有 API**：它像真人一樣操作 Flow 網頁：填入提示詞、按「開始生成」、等待結果。

## 安裝

1. 開啟 `chrome://extensions`，打開右上角的「開發人員模式」。
2. 按「載入未封裝項目」，選擇 `G:\flow_extension\flow-queue`。
3. 要在哪個 Chrome 設定檔（Profile）使用，就在那個設定檔裡載入。

## 使用方式

1. 開啟 Flow 專案頁面（`https://flow.google.com/project/...`）。
2. 先在 Flow 介面設定好模型、比例、輸出數量。佇列會沿用目前的設定。
3. 點工具列上的圖示，或按 `Alt+Shift+Q`，打開側邊面板。
4. 貼上提示詞，選擇分割方式：
   - **以空行分隔**：提示詞之間空一行，可以是多行提示詞。
   - **每行一個**：每一行是一個提示詞。
5. 按「加入佇列」，再按「開始」。

## 功能

- **排隊送出**：依序送出提示詞，或設定「同時生成數」，讓多筆同時在 Flow 生成。
- **隨機間隔**：每次送出之間隨機等待一段時間，降低被判定為異常的機率。
- **自動判斷結果**：
  - 用 Flow 的生成中、錯誤、結果磚判斷每筆提示詞完成或失敗。
  - 失敗時依設定自動重試。
- **限流保護**：
  - 遇到「請稍後再試」之類的提示，會冷卻一段時間再繼續。
  - 遇到「異常活動」或「點數不足」，會直接停止佇列，保護帳號。
- **不重複扣點數**：
  - 逾時或無法確認結果的項目標為「未確認」，不會自動重送。
  - 你確認後可以手動按「重試」。
- **佇列管理**：調整順序、置頂、編輯、刪除、重試、清除，以及複製失敗的提示詞。
- **自動下載（選用）**：完成後下載到 Chrome 下載目錄底下的資料夾（預設 `FlowQueue/`）。
- **重新整理後接手**：Flow 頁面重新整理後，仍在生成中的項目會重新接手追蹤。

## 注意事項

- **真實點擊**：
  - Flow 需要真實的點擊事件才會開始生成，所以預設用 `chrome.debugger` 送出滑鼠點擊。
  - 執行時瀏覽器上方會出現「正在偵錯此瀏覽器」的提示，這是正常的。
  - 如果按了該提示的「取消」，會自動改用一般點擊。一般點擊可能比較不穩定。
- **前景執行**：Flow 分頁保持在前景（例如放在獨立視窗）最穩定。背景分頁的計時器會被 Chrome 降速。
- **離開專案會停止**：執行時若切換到別的 Flow 專案，佇列會自動停止，避免送錯專案。
- **下載畫質**：自動下載抓的是 Flow 網格上的媒體網址。圖片可能是預覽尺寸，最高畫質請在 Flow 裡下載。
- **介面改版**：Flow 改版後，DOM 選擇器可能需要更新。選擇器都集中在 `content.js` 開頭的「Flow DOM」區塊。

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `manifest.json` | 擴充功能設定 |
| `background.js` | 佇列狀態的唯一寫入者，也負責真實點擊（debugger）與下載 |
| `content.js` | 在 Flow 分頁內執行的排隊器（填入、送出、追蹤完成） |
| `sidepanel.*` | 側邊面板介面 |
